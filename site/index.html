Individual · SME · Organization — one workspace, different starting points.

รับงาน ขาย ซื้อ ติดตามการส่งมอบและเอกสาร พร้อมผู้ช่วย AI ในเครื่องที่อ่านข้อมูลตามสิทธิ์ของผู้เข้าสู่ระบบ ไม่สร้างหรืออนุมัติรายการแทนคุณ

ดาวน์โหลด boombignose-v0.3.0 ดูขั้นตอนทำงาน

เลือกตัวติดตั้งของระบบคุณจาก Release ที่เผยแพร่แล้วด้านล่าง

ข้อมูลและการอนุมานอยู่บนเครื่องที่ให้บริการ ERP; การดาวน์โหลดโมเดลต้องใช้อินเทอร์เน็ตและการสั่งของผู้ใช้

  • Local inference
  • Human review
  • Private access

เลือกจุดเริ่มตามงาน

โปรไฟล์เปลี่ยนเมนูเริ่มต้นและทางลัด ไม่เปลี่ยนข้อมูล ประเภทธุรกิจตามกฎหมาย หรือสิทธิ์บัญชี โมดูลอื่นที่คุณมีสิทธิ์ยังเปิดได้จากเมนูเพิ่มเติม

Individual · งานส่วนตัว

รับบรีฟงาน จัดโปรเจกต์ บันทึกเวลาฟรีแลนซ์ และติดตามใบแจ้งหนี้ เห็นงานที่เกี่ยวข้องกับคุณก่อน

SME · ธุรกิจประจำวัน

เริ่มที่ใบเสนอราคา ลูกค้า จัดซื้อ ผู้ขาย และสต็อก เพื่อเดินงานขายและรับสินค้าในพื้นที่เดียว

Organization · ข้ามทีม

ตรวจภาระงาน ส่งมอบ ค่าใช้จ่าย และรายงาน พร้อมทางลัดจาก Organization3D ไปยังรายการที่ต้องจัดการ

หน้าจอของเวิร์กโฟลว์ปัจจุบัน

แต่ละช่องกำหนดไว้สำหรับภาพจากแอปจริงที่ใช้ข้อมูลสาธิตสังเคราะห์ ไม่ใช่แดชบอร์ดวาดเลียนแบบ และไม่ใช้ภาพรุ่นเก่ามาแทนหน้าจอที่เปลี่ยนแล้ว

สถานะการรวมซอร์ส: ภาพชุดปัจจุบันและการตรวจในเบราว์เซอร์ยังรอการรวมระบบ ภาพที่ระบุในหน้านี้ไม่ใช่หลักฐานว่ารุ่นดาวน์โหลดมีฟีเจอร์ใหม่แล้ว โปรดอ่านบันทึกของ Release ก่อนติดตั้ง

สามมุมมอง คนละคำถาม

ภาพสามมิติเป็นเครื่องมือสำรวจ ไม่ใช่หลักฐานว่าการทำงานหรือเครือข่ายปลอดภัย

Organization3D

ภาระงาน ERP จริงตามสิทธิ์: งานส่งมอบ ใบเสนอราคา ค่าใช้จ่าย และโมดูลจัดการที่บัญชีคุณเข้าถึงได้ มีรายการและลิงก์ต้นทาง ไม่ใช่รถยกหรือกิจกรรมคลังที่สมมติขึ้น

Network3D

ภาพ snapshot ของ established TCP จาก native macOS collector เท่าที่ OS อนุญาต ไม่อ่าน payload ไม่ครอบคลุม UDP หรือทุกการเชื่อมต่อ ข้อมูลเก่า/ขาด/ถูกตัดเป็น unknown; สัญญาณต้องให้คนตรวจ

Blueprint

แผนภาพโครงสร้างโมดูลและขั้นตอน ERP พร้อมยอดรวม/สถานะตามสิทธิ์ ไม่ใช่เครื่องสแกนเครือข่ายหรือผังอุปกรณ์จริง

AI ช่วยอ่าน
คนยังเป็นผู้ตัดสินใจ

ไม่มี cloud inference fallback แต่ความเป็น local ไม่ทำให้คำตอบถูกต้องโดยอัตโนมัติ

ถามข้อมูลที่คุณอ่านได้

ผู้ช่วยใช้เครื่องมืออ่านอย่างเดียวตาม workspace และบทบาทของ session ไม่ให้โมเดลเลือกองค์กรเอง ข้อมูลที่อ่านไม่สำเร็จไม่ถูกตีความเป็นยอดศูนย์

ดูที่มาและส่วนที่ขาด

คำตอบแยกหลักฐานและข้อจำกัด รายการที่อ่านมาไม่ครบไม่ใช่ยอดรวมทั้งองค์กร ข้อเสนอแนะไม่ใช่การสร้าง จ่าย อนุมัติ หรือลบรายการแล้ว

OCR เป็นข้อเสนอ

รองรับภาพ JPEG, PNG, WebP และ PDF ภายในขีดจำกัดของแอป เอกสารที่อ่านไม่ชัดหรือวันที่กำกวมต้องตรวจเอง ไม่มีคะแนนความแม่นยำที่รับประกัน

การเงินมีขั้นตอนตรวจ

ตรวจยอด ภาษี วันที่ และเอกสารต้นฉบับก่อนบันทึก เอกสารดำเนินงาน/ส่งออกไม่ใช่การยื่นภาษี ลายเซ็นรับรอง หรือคำปรึกษากฎหมาย

เครื่องส่วนตัว หรือเซิร์ฟเวอร์ส่วนตัว

เปิดบนเดสก์ท็อป

ตัวติดตั้งพก native launcher และบริการ ERP ในเครื่อง ไม่ต้องติดตั้ง Node หรือ Docker แยก น้ำหนักโมเดลไม่รวมอยู่ในไฟล์ ให้เลือกดาวน์โหลดด้วยตนเอง

ตั้ง native server

ใช้คำสั่ง serve / stop / check กับโฟลเดอร์ข้อมูลที่กำหนด ดู ขั้นตอนเซิร์ฟเวอร์ อย่าเปิด Postgres, Auth, REST หรือ Ollama ออกเครือข่าย

เข้าแบบ private Tailscale

ให้ Serve ส่ง HTTPS ไป ERP บน loopback เฉพาะ tailnet ที่อนุญาต โทรศัพท์ยังต้อง login และ MFA ตามบัญชี ห้ามใช้ Tailscale Funnel หรือ public tunnel แทนระบบสิทธิ์

ไฟล์แต่ละระบบ

ลิงก์และ SHA-256 ด้านล่างผูกกับ Release boombignose-v0.3.0 ที่เผยแพร่แล้ว ไม่ใช่หลักฐานว่าฟีเจอร์ในซอร์สที่รอรวมระบบอยู่ในตัวติดตั้งนี้ น้ำหนักโมเดลไม่รวมในไฟล์ ไม่มี Developer ID/notarization หรือ Authenticode ที่หน้านี้รับรอง โปรดอ่าน วิธีติดตั้ง และบันทึกของรุ่น

ขอบเขตที่ควรรู้ก่อนใช้

Local ไม่เท่ากับผ่านกฎหมายแล้ว

ผู้ดูแลยังต้องกำหนดสิทธิ์ ระยะเก็บข้อมูล สำรอง/กู้คืน ปรับปรุงระบบ และจัดการเหตุการณ์ตามบริบทกิจการ หน้านี้ไม่รับรอง PDPA มาตรฐานความปลอดภัย หรือความถูกต้องทางบัญชีและภาษี

ดาวน์โหลดอย่างรู้ที่มา
