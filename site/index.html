สามขั้น

Three steps from download to a running window.

1

เลือกไฟล์ของระบบ

เวอร์ชัน boombignose-v0.3.0 มีตัวติดตั้งสำหรับ macOS arm64, Windows x64 และ Linux amd64 พร้อม Node, server.js, Postgres, Auth, PostgREST และ Ollama ในไฟล์เดียวกัน ไม่รวมน้ำหนักโมเดล qwen2.5:3b ขั้นตอนเปิดไฟล์อยู่ที่ วิธีติดตั้ง

2

ยอมรับคำเตือนของระบบ

ไม่มีใบรับรองที่ซื้อจากร้านค้า macOS ใช้ Open Anyway Windows ใช้ More info แล้ว Run anyway Smart App Control อาจยังบล็อก

3

เปิดหน้าต่าง

โปรแกรมที่ติดตั้งชื่อ BoomBigNose และเปิดเป็นหน้าต่าง ชุดนี้สตาร์ท ERP ในเครื่องที่ 127.0.0.1:3100 ไม่รวม Docker และไม่ดาวน์โหลดโมเดลเอง การดึง qwen2.5:3b เกิดเมื่อผู้ใช้กดปุ่มหรือรัน boombignose pull-model เท่านั้น ยังไม่ถูกคลิกทดสอบบนเครื่องจริง

ไฟล์แต่ละระบบ

สร้างจาก CI ของแท็ก boombignose-v0.3.0 ขนาดเป็นไบต์ตาม Release ค่าแฮชทั้งไฟล์มาจาก SHA256SUMS ของแท็กนั้น ชุดนี้รวมหน้าต่างกับ Node, server.js, Postgres, Auth, PostgREST และ Ollama v0.40.11 ไม่รวมน้ำหนักโมเดล และไม่ได้ลงชื่อด้วยใบรับรองที่ซื้อมา Linux กับ Windows ไม่รวมตัวรัน CUDA วิธีเปิดไฟล์อยู่ที่ หน้าติดตั้ง

เปิดไฟล์ที่ไม่ได้ลงชื่อ

The installers are not signed with a purchased certificate, so your OS will warn first.

macOS

  1. เปิดไฟล์ .dmg
  2. ถ้าเปิดไม่ได้ ให้คลิกขวาที่ไฟล์แล้วเลือก Open
  3. หรือไปที่ Privacy & Security แล้วกด Open Anyway
  4. เครื่องจะไม่ข้ามคำเตือนให้เอง

Windows

  1. เปิดไฟล์ .exe
  2. ถ้า SmartScreen ขึ้น ให้กด More info แล้ว Run anyway
  3. Smart App Control อาจบล็อกแอปที่ไม่ได้ลงชื่อ
  4. การกด Run anyway อาจไม่พอ ต้องตรวจการตั้งค่าบนเครื่องนั้น

Linux

  1. แตกไฟล์ .tar.gz แล้วได้โปรแกรมชื่อ BoomBigNose และโฟลเดอร์ bundle หรือใช้ไฟล์ AppImage
  2. ต้องมี WebKitGTK 4.1 ในระบบ
  3. เปิดแล้วเป็นหน้าต่าง ไม่ใช่คำสั่ง harness
